# myFirstGit

## Project Description

This is my first Git and Node.js project. It prints "Hello World" to the console.

## Installation

1. Clone the repository:

```bash
git clone https://github.com/JacobGS97/myFirstGit.git
```

2. Open the project folder:

```bash
cd myFirstGit
```

3. Install the project dependencies:

```bash
npm install
```

## Running the Project

Run the following command in the terminal:

```bash
node index.js
```

The expected output is:

```text
Hello World
```
